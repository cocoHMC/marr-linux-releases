# Tonarr and Cinemarr for Linux

Official binary releases for x86_64 Omarchy from Pragmatic Developments Inc.
Both apps connect to your own media servers; they do not provide media.
A Media Pass and a compatible server are required.

Download installable packages from [Releases](https://github.com/cocoHMC/marr-linux-releases/releases).
Each release includes checksums, validation scope, dependency notices, and the
corresponding source and build recipes for bundled playback libraries.

Application source is maintained in the existing private development repository.
This repository is a public distribution channel, not another development branch.
Third-party components retain their respective licenses; the applications are
provided under [Pragmatic's terms](https://pragmatic.onl/terms).
